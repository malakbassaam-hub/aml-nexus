# AML-Nexus
**Catch the criminals. Protect everyone else.**

An AML compliance copilot prototype. It detects laundering patterns in a transaction graph (fan-in "smurfing", closed loops),
shows evidence *for and against* each suspicion, and recommends a graduated response
(Clear / Verify / Monitor via Evidence Watch / Escalate). **It only recommends; a human reviewer decides.**

> **All data is synthetic. No real customers or transactions.** Results below describe synthetic data
> generated by this repo and are not claims about real banks. A bank would need to validate on its own data and policies.

## Run
```
pip install -r requirements.txt
python -m unittest discover -s tests -t .
python -m src.evaluate
```

## Status
- [x] Synthetic data: legit look-alikes (shops, charities, promos, fundraisers, payroll, friend loops), planted laundering (typical, stealth, evasive, loops), noise
- [x] Fan-in and cycle detectors, evidence for AND against, tier recommendation (Clear / Verify / Monitor / Escalate)
- [x] Evidence Watch + keep-open record (purpose, duration cap, review cadence, auto-expiry), tamper-evident audit log
- [x] Automation-bias guard (reviewer agreement, time, counter-evidence opened) and friction before confirming an escalation
- [x] Multi-seed evaluation: calibrated on dev seeds, reported on held-out seeds (`docs/results.json`)
- [ ] Streamlit dashboard, PayPal Sandbox webhook, LLM case summary (summarizes existing evidence only)

## Honest results (synthetic data, 10 held-out seeds)
- Planted laundering accounts flagged for Monitor/Escalate: ~88% on average (worst seed 83%). Evasive rings are often missed.
- Innocent accounts at freeze-level (Escalate): 0. Innocents sent to Verify: ~10 per seed; to Monitor: ~3 per seed.
- A naive count-based rule at matched detection rate flagged ~31 innocents per seed, and could not reach our detection rate in 6 of 10 seeds.
- Limits: the data generator and detectors were written by the same authors; thresholds are policy parameters, not legal advice or validated limits.
